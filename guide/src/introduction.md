# Sailing on a croisière

## Introduction

`croisiere` is an opinionated rust domain-driven design application framework that helps you build scalable applications quickly.

This guide expects the reader to know about the basics of DDD.

## Opinionation

`croisiere` is opinionated. This means that it has taken major application and software design choices for you already.
You will find its design choices below.

My major source of inspiration for this framework is Herberto Graça's series on software design called [The Software Architecture Chronicles](https://herbertograca.com/2017/07/03/the-software-architecture-chronicles/), and especially [chapter 17: DDD, Hexagonal, Onion, Clean, CQRS, ...How I put it all together](https://herbertograca.com/2017/11/16/explicit-architecture-01-ddd-hexagonal-onion-clean-cqrs-how-i-put-it-all-together/). If you want to understand my design choices, and therefore the design that ended up making `croisiere`, I'd heavily recommend giving that chapter a read.

Most other principles come from discussions with myself or with AI.
